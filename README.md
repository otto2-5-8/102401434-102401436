## 项目成员

- 102401434 包学丰

## 项目说明

本项目是2026秋软件工程第二次结对作业，基于第一次作业完成的需求分析和原型，实现校园失物招领系统的核心功能。

## 主要功能

- 浏览寻物和招领信息
- 发布寻物信息
- 发布招领信息
- 搜索物品
- 查看详情及联系方式
- 修改信息状态
